CadTech Truss Design Studio V10.2 — drawing presentation updates

- Member marks (TC/BC/W labels) are plain text without circular badges or white backgrounds.
- Vertical dimensions are always rendered vertically, including short dimensions.
- Schematic connector plates are smaller relative to the timber outline so wood joints remain visible.
- Added File / drawing units selector in Analysis + Reports. Default is Feet / inches (fractions to 1/16 in); Metric (mm / m) can be selected for PDF reports.
- OBJ/CAD import units remain separate from output/report units: change import units to match the source file, and use File / drawing units to change PDF dimension display.

Engineering note: connector plates remain schematic placeholders and are not fabrication designs. Verify geometry and all engineering checks before issue.
